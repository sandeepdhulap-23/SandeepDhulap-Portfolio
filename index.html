WRITING SAMPLE

Sample Troubleshooting Article

The Application Is Blocking Requests to the Server

Problem

The application displays an error indicating that requests to the server are currently being blocked.

Possible Cause

The application firewall or request-processing mechanism may be preventing requests from being processed.

Solution

  1. Navigate to the application's web server state directory.
  2. Create a file named inactive.txt.
  3. Save the file in the appropriate fw/state directory.
  4. Retry the application request.

Verification

Verify that the application processes requests successfully without displaying the blocking message.
